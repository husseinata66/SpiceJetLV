## 3. Findings

1. **Defect** — The seat map offers seat 5F (SG 612, a plain Window seat) to an adult holding an infant, but the airline refuses it at booking: "Seats cannot be assigned … seat group eligibility may not be met … anchor unit Y/5F was not selected … insufficient number of available seats for 1 passenger (2 total)" → status Failed. With the adult on 5D the same Admin booking is Confirmed (PNR VBLU2T, 29 Oct). This was behind every earlier Admin infant failure (Groups 14, 15). (Groups 14, 15)
2. **Defect** — The leg space rule is enforced inconsistently at Book on Admin: an adult holding an infant on leg space seat 2A (a Window seat carrying the Leg space label) was Confirmed (PNR T52R8Y) and the wallet charged 8,937 — the rule says Failed, no charge. The same booking on leg space seats 2B (28 Oct) and 2C (29 Oct) was refused correctly, so TC-SM-LEG-003 shows Passed on its latest run; seat 2A is the exception. (TC-SM-LEG-003 · Group 20, 29 Oct 05:59 run)
3. **Runner gap** — After the Confirmed Admin booking (Group 14) the runner could not select Admin's "by booking reference" option on the itinerary lookup (#id-GetItineraryDetailsBy-BookingRef.), so the itinerary / costing / meal / bag checks were Blocked — not an application finding. (TC-SM-CNF-011, CNF-012, ML-005, BG-005, RPT-001 · Group 14)
4. **Defect** — Multi-city Trip 3 (DEL→BLR, direct, 02-11-2026) offers no baggage: 4 baggage boxes for 3 journeys × 2 passengers, labelled Trip 1 and Trip 2 only — on Admin and Portal, 28 and 29 Oct. On 28 Oct Trip 3 had no meal either (8 meal boxes for 10); on 29 Oct all three journeys were direct and every flight had meals (6 of 6), so TC-SM-MCT-007 was Inconclusive (no connecting journey to judge). (TC-SM-MCT-006, TC-SM-MCT-007 · Group 10)
5. **Open question** — The two flights of a connecting journey price seats differently (e.g. Trip 1: up to EGP 999 on one leg, EGP 149 on the other). TC-SM-MCT-007 expects the same; this may be normal per-aircraft pricing for Spicejet — business decision pending. (TC-SM-MCT-007)
6. **Runner gap (fixed)** — TC-HLD-005 failed on Admin because the runner added up the held booking's extras itself and did not recognise the bag line "EB30 13,500 EGP" (a code with digits). PNR Query does list the bag; parser fixed 29 Oct and covered by a test. Not an application defect. (TC-HLD-005 · Group 17)
7. **Defect** — After Hold → Pay after hold on Admin the booking is "Booked" and the wallet is charged exactly the held amount (19,344, TC-PAH-002 Passed), but there is no ticket number — the same as on the Portal. (TC-PAH-004 · Group 17, 29 Oct, ref NDCEG-BR-F261029WKsCaN)
